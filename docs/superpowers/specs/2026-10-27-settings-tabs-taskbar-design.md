# 设置 Tab 与任务栏布局修正

用户明确要求取消设置分页、改多 Tab，并修复任务栏只有网速且留白的问题。本次以该具体交互要求为已授权设计，不再增加审批环节；不提交/推送。

- 设置采用原生 SysTabControl32，按常规、悬浮窗、任务栏、显示项目、提醒、高级、皮肤与语言分为7个Tab。取消每32字段分页。切Tab保留draft，统一应用/确定/取消；切Tab不写配置或系统启动项。
- 所有13内置项目及加载插件可通过友好名称勾选、排序。新配置默认上传/下载/CPU/内存；已有显式选择保留。取消全部即不显示，不解释为显示全部。
- 任务栏默认自动适应已选内容。旧默认180宽迁移为自动，自定义固定宽度可保留；界面提供明确自动/固定选择。只为实际可见项目保留宽度，选项减少/插件消失/全不选时恢复空间；保留双行、DPI、插件宽度和Explorer几何恢复。
- 数值测量按旧digits_number提供稳定最小数字宽度，避免网速每次改变引发抖动；不恢复180像素空白下限。
- GUI只操作隔离测试实例，不关闭现有用户实例。构建替换遇到运行文件锁时另存可运行包。

验收：定向红绿回归、x64/x86格式/Clippy/相关测试和Release、真实Tab切换/Apply/Cancel/显示勾选及任务栏缩放截图。当前实现与设备矩阵证据分别记录。
